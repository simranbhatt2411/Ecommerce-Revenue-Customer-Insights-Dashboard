# Ecommerce Revenue & Customer Insights Dashboard
### SQL + Power BI Analytics Project

## Overview
End-to-end ecommerce sales analysis using SQL and Power BI across 2 datasets 
(1,500 orders + 500 order details). The dashboard provides insights into sales 
performance, profitability, customer behavior, category trends, and payment 
preferences using relational data connected through Order_ID.

## Tools & Technologies
SQL | MySQL | Power BI | DAX | Excel

## Dataset
- **Orders Table** (1,500 records) — Order_ID, Order_Date, Customer_Name, City, State
- **Details Table** (500 records) — Order_ID, Amount, Profit, Quantity, Category, Sub_Category, PaymentMode

## SQL Concepts Used
JOINs | GROUP BY | Aggregations | ORDER BY | KPI Calculations

## Key Insights
- Tracked overall revenue, profit, and average order value across categories
- Identified top-performing states, customers, and payment modes
- Analyzed category-wise and sub-category-wise profitability
- Discovered growth opportunities through regional and customer segmentation

## KPI Metrics
Total Revenue | Total Profit | Profit Margin | AOV | Quantity Sold | 
Category-wise Revenue | State-wise Profit | Customer Revenue Analysis

## Files Included
- `Sales_Dashboard.pbix` — Editable Power BI dashboard
- `Sales_Dashboard.pdf` — Dashboard preview
- `SQL_Queries.sql` — SQL analysis queries
- `README.md` — Project documentation

## How to Use
1. Download `.pbix` and open in Power BI Desktop
2. Run `SQL_Queries.sql` in MySQL Workbench for backend analysis
